# respondeR web app

A client-side (no server, no R) responder-analysis tool built with React, Vite,
TypeScript and Tailwind. The statistics in `src/lib/engine.ts` are a faithful
port of the `respondeR` R package and are checked against R output by a parity
test (`src/lib/__tests__/parity.test.ts`, fixture generated by
`tools/gen_reference.R`).

Deployed at <https://choxos.github.io/respondeR/app/>.

```sh
npm install
npm run dev        # local dev server
npm run typecheck  # tsc --noEmit
npm test           # vitest (engine + parity)
npm run build      # production build to dist/
```

To regenerate the parity fixture after changing the R engine, from the
web app branch root:

```sh
Rscript tools/gen_reference.R
```
